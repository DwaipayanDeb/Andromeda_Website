📦 Automated Dependency Resolution

Andromeda Writer uses the native system web rendering engine (WebKitGTK). When installed via .deb, .rpm, Flatpak, or Snap, all required libraries (libwebkit2gtk-4.1-0, libgtk-3-0) are automatically downloaded and configured in one shot with zero manual intervention.
